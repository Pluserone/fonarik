# 🔦 Скевоморфный Фонарик («ЭТО ФОНАРИК»)

Мобильное приложение-фонарик премиум-класса с физическим скевоморфным интерфейсом, разработанное для марафона стартапов **Pluser**.

---

## 📱 Особенности приложения

1. **Скевоморфный минимализм и физическая глубина:**
   - **Светлая тема (Light Mode):** мягкий матовый пластик корпуса, многослойные реалистичные тени продавленной ниши, рельефная цилиндрическая кнопка с тактильным откликом.
   - **Тёмная тема (Dark Mode):** глубокий угольно-чёрный фон, эффект мягкой белой подсветки и неонового свечения из пустоты ниши, светящаяся кнопка и светящаяся Луна в углу экрана.
2. **Физический переключатель (ON / OFF):**
   - Плавное перемещение цилиндрической кнопки в углублении.
   - Поддержка как тапа в любую точку слайдера, так и плавного вертикального свайпа.
   - Тактильный виброотклик (Haptic Feedback) при переключении.
   - Значок питания (Power ⏻) в центре цилиндра.
3. **Управление вспышкой телефона:**
   - Мгновенная активация вспышки камеры устройства.
   - Безопасная обработка отсутствия вспышки (на эмуляторах).
   - Автоматическое выключение фонарика при сворачивании приложения для сохранения аккумулятора.
4. **Интерактивная ссылка:**
   - Кнопка перехода в Telegram-канал `t.me/pluseron`.
5. **Готовая иконка приложения:**
   - Все размеры для рабочего стола Android уже сгенерированы в папках `res/mipmap-*`.

## 🚀 Пошаговая инструкция: Запуск и сборка готового .apk

### Шаг 1. Установка Flutter SDK
Если Flutter ещё не установлен на вашем компьютере:
1. Скачайте [Flutter SDK](https://docs.flutter.dev/get-started/install) с официального сайта.
2. Распакуйте (например, в `C:\src\flutter`) и добавьте путь `C:\src\flutter\bin` в переменную окружения `PATH`.
3. Установите **Android Studio** и в ней компоненты **Android SDK Platform-Tools** и **Android SDK Build-Tools**.

### Шаг 2. Загрузка зависимостей
Откройте терминал в папке проекта (`c:\Users\Я.HOME-PC\Desktop\фонарик`) и выполните:
```bash
flutter pub get
```

### Шаг 3. Запуск для проверки (Debug)
Подключите телефон по USB с включённой «Отладкой по USB» (или запустите эмулятор) и введите:
```bash
flutter run
```

### Шаг 4. Сборка готового установочного файла (.apk)
Для получения оптимизированного релизного `.apk` файла выполните:
```bash
flutter build apk --release
```

После завершения компиляции ваш файл появится по адресу:
```text
build/app/outputs/flutter-apk/app-release.apk
```

**Этот `.apk` готов к отправке на любой Android-смартфон и установке!**
